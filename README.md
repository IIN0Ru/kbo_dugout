# DUGOUT

야구 선수와 팬이 1:1 대화처럼 소통하는 버블형 서비스의 웹 프로토타입입니다.
경기대학교 캡스톤 디자인 발표용 목업이며, 실제 구단·선수와 무관합니다.

## 현재 범위

- 첫 화면: 유니폼 줄무늬 위 `#dugout` 대화방. 보낸 사람(DUGOUT)과 입력 중 → 서비스 설명 메시지 → 입력 중 → 입장권 도착 → 그 아래 오른쪽 팬(나) 말풍선에서 입력 중(…)이 계속 깜빡인다. 열거나 새로고침할 때마다 처음부터 다시 재생된다.
  - 입장권 '입장' 꼬리가 첫 화면의 유일한 버튼(마우스를 올리면 반쯤, 누르면 완전히 찢어짐)
  - 누르면 로그인·회원가입 화면으로 갈 예정. 다음 단계에서 react-router로 연결하고, 지금은 티켓이 찢어졌다가 다시 붙기만 한다.
- 문구·타이밍은 `src/landing.js`에서 고친다.

## 공유 미리보기

`public/og.png`(1200×630)는 첫 화면 캡처예요. 첫 화면 디자인이 바뀌면 다시 찍어야 해요.

## 실행

```bash
npm install
npm run dev              # 개발 서버
npm run build            # 일반 배포용 빌드 (dist/)
npm run build:artifact   # Claude 공유 링크용 단일 HTML (artifact/dugout.html)
```

## 구조

```
src/
  landing.js              첫 화면 문구와 연출 타이밍
  styles.css              디자인 토큰과 전체 스타일
  App.jsx                 첫 화면 조립 (로고, 대화방)
  components/
    ChatRoom.jsx          #dugout 대화방, 메시지 등장 순서
    Ticket.jsx            입장권과 찢기 동작
```

## 디자인 기준

| 항목 | 값 |
| --- | --- |
| 바탕 | 오프화이트 `#FDFBF6` |
| 줄무늬 | 빨강 6px · 간격 48px · 진하기 55% |
| 메인 빨강 | `#B3202A` |
| 검정 · 강조 | `#000000` · 전광판 노랑 `#F5C400` |
| 글꼴 | 로고·티켓·버튼 Black Han Sans / 본문 IBM Plex Sans KR / 티켓 영문 IBM Plex Mono |
| 모서리·그림자 | 티켓 양옆 펀치 홈, 대화방 4px, 번지지 않는 검정 그림자 |
| 크기 | 브레이크포인트 없이 화면 폭에 따라 이어서 변함. `src/styles.css` 맨 위 '크기' 묶음에서 조절 |
| 배치 | 채팅방 + 튀어나온 티켓을 한 덩어리로 화면 가운데, 로고는 왼쪽 위 |

## 글꼴

구글 폰트를 불러오지 않고 프로젝트에 포함했어요(자주 쓰는 한글 2,350자 + 영문으로 줄인 woff2). 블랙한산스는 `public/fonts`(미리 받기용), 나머지는 `src/assets/fonts`에 있어요. 공유 링크용 빌드에서는 CSS 안에 직접 들어가요. 화면에 없는 드문 글자가 필요해지면 원본 TTF에서 다시 줄여야 해요.
